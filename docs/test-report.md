COM 등록과 문서 입력 단계의 진행을 저장·변환 성공으로 간주하지 않았습니다. 저장 중 사용자에게 창 표시 여부를 확인했으며, 표시된 창이 없다는 답변을 받았습니다. 원인은 확정하지 못했습니다.

원래 스킬 제작 도구의 `quick_validate.py`는 PyYAML이 없어 실행하지 못했습니다. 추가 패키지를 설치하지 않고 직접 검사했습니다.

## 실제 HWPX 편집 테스트

한글 설치에 포함된 `공문서_양식_템플릿_일반.hwpx`를 원본으로 사용했습니다. 원본을 바꾸지 않고 별도 파일에 텍스트 한 곳을 `hwp 스킬 실제 HWPX 편집 테스트`로 바꿨습니다. 해당 문단의 줄 배치 캐시는 제거했습니다.

- 본문 변경 위치: `Contents/section0.xml`
- 나머지 12개 엔트리: 압축 해제한 내용의 바이트 동일성 확인
- 결과 텍스트: XML을 다시 읽어 수정된 문구 존재 확인
- 결과 ZIP/XML: `validate_hwpx.py` 통과
- 한글에서 열기·쪽수·스타일 참조 전체·출력 화면: 미확인

이 검사는 ZIP 압축 바이트나 모든 XML 직렬화의 원본 동일성을 보장하지 않습니다. 본문 XML은 재직렬화됩니다. 보고서 서식 전체를 교정한 테스트도 아닙니다. 한글에 포함된 양식 및 파생 테스트 파일은 이 공개 저장소에 게시하지 않았습니다.

정상 HWPX 양식을 보유한 사용자는 다음과 같이 로컬에서 재현할 수 있습니다.

```sh
python tools/package-smoke.py --template "원본양식.hwpx" --output "outputs/package-smoke/sample.hwpx"
```

결과 파일과 함께 `.report.json`이 생깁니다. 기존 출력 파일이 있으면 덮어쓰지 않고 중단합니다. 이 도구는 한 곳의 텍스트를 바꾸는 편집 시험용이며 일반 보고서 작성기로 사용하지 않습니다.

## 자동 테스트 재현

```sh
python install.py --check
python tools/check_skill.py
python -m unittest discover -s tests -v
```

설치 테스트는 임시 디렉터리를 사용합니다. 실제 개인 스킬과 사용자 문서를 덮어쓰지 않습니다. HWPX 검사기 테스트의 작은 ZIP은 **검사기용 합성 입력**이며 실제 한글 문서로 열렸다고 주장하지 않습니다. Windows 실행 파일 테스트는 다른 운영체제에서 건너뜁니다.

GitHub Actions 설정은 Linux·Windows에서 Python 3.10·3.12로 같은 검사를 실행하도록 추가했습니다. Actions의 원격 실행 결과는 [Actions 페이지](https://github.com/Drjinhs/hwp/actions)에서 확인합니다. 이 문서에 적힌 10개 통과는 로컬 Windows 결과입니다.

## 한글 자동화 시험 재현

Windows에 한글이 설치되어 있는 환경에서 아래 명령을 사용합니다. 실행할 때마다 새로운 출력 폴더를 지정하세요.

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\tools\native-smoke.ps1 -OutputDirectory .\outputs\native-test-01
```

스크립트는 새 COM 객체를 만들고 한국어 샘플을 입력한 뒤 HWPX/HWP 저장 → 저장 파일 재열기 → 본문 확인 → PDF 저장을 순서대로 시도합니다. 사용자의 기존 문서를 연결해서 편집하지 않습니다. 글꼴은 실제 설치 목록을 확인해 휴먼명조, 없으면 함초롬바탕을 사용하며 성공 보고서에 선택한 글꼴을 적습니다. 샘플은 저장 시험용으로, 실무 보고서의 빈 문단·제목 디자인 등 모든 서식 기준을 재현한 양식은 아닙니다.

예상하지 못한 창이나 응답 없는 대기가 발생하면 중단하고 한글의 상태를 확인하세요. 이 스크립트 자체에는 자동 타임아웃이 없으므로 성공 결과를 기다리며 무기한 방치하지 마세요. 사용 중인 다른 한글 프로세스를 일괄 종료하지 마세요. 이번 환경에서는 저장 단계가 대기하여 시험을 중단했습니다.

한글 Windows 자동화와 웹한글 API는 지원 범위가 다를 수 있습니다. 관련 원문은 [한컴 Windows 자동화 자료](https://github.com/hancom-io/devcenter-archive/tree/main/hwp-automation)에서 확인할 수 있습니다.
